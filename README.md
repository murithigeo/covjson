###

A monorepo containing the various tools to process and visualize CoverageJSON Documents.

Houses the following modules:

| Module                              | Description                                                                                                       |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| [core](./core)                      | The core utils for manipulating CoverageJSON documents. Enables operations such as data fetchs, reprojections etc |
| [Maplibre Plugin](./plugin-leaflet) | Plugin handling rendering CoverageJSON rendering in [Maplibre](https://maplibre-gl.com)                           |
| [Leaflet Plugin](./plugin-leaflet/) | Plugin handling rendering CoverageJSON rendering in [Leaflet](https://leaflet-js.com)                             |
